

# 人体姿态估计 深度学习经典必读论文

1. DeepPose: Human Pose Estimation via Deep Neural Networks (CVPR, 2014)

首个使用深度卷积神经网络实现人体姿态估计, **regression方法**

2. Efficient Object Localization Using Convolutional Networks (CVPR, 2015) 首个使用**heatmap方法**

3. OpenPose经典多人姿态估计方法，**Bottom-Up**

4. AlphaPose (RMPE) RMPE: Regional Mlulti-Person Pose Estimation (2018) **Top-Down**

5. DeepCut: Joint Subset Partition and Labeling for Multi Person Pose Estimation **Bottom-Up方法**

6. Mask RCNN人体检测和关键点检测独立并行，类似**Top-Down方法**

7. Simple Baselines for Human Pose Estimation and Tracking (EECV, 2018)

8. HRNet Deep High-Resolution Representation Learning for Visual Recognitior

9. RLE : Human Pose Regression with Residual Log-likelihood Estimation
