# 图像分割：从 CNN 到 Transformer 速通

## 一、任务与指标

- **语义分割**：给每个像素分类，不区分个体（所有"人"是同一类）。
- **实例分割**：区分同类的不同个体（人1、人2），通常只管"物体"类。
- **全景分割**：语义 + 实例，既有"物体"也有"背景"（天空、道路）。
- **指标**：语义分割看 **mIoU**（每类 IoU 的平均）、Dice；实例分割看 **mask AP**；全景分割看 **PQ**（= 分割质量 × 识别质量）。

## 二、CNN 时代：核心算法

**1. FCN（2015）**：奠基之作。把分类网络最后的全连接层换成卷积，得到密集预测；用转置卷积上采样，并融合浅层特征（skip）恢复细节。
- 问题：下采样太多，边界粗糙。

**2. U-Net（2015）**：编码器-解码器对称结构，解码时把对应层的编码器特征 **concat** 过来。浅层提供细节和位置，深层提供语义，小数据集（医学影像）上表现很好，至今仍是最常用的基线。

**3. DeepLab 系列**：解决"下采样丢分辨率 vs 感受野"的矛盾。
- **空洞卷积（Dilated/Atrous Conv）**：不增加参数的前提下扩大感受野，同时不下采样。
- **ASPP**：并行多个不同膨胀率的空洞卷积，捕获多尺度上下文。
- v1/v2 用 CRF 后处理精修边界，v3+ 去掉 CRF，加入轻量解码器和深度可分离卷积。

**4. PSPNet**：金字塔池化模块，用不同尺度的全局池化聚合上下文，思路与 ASPP 类似（多尺度上下文）。

**5. HRNet**：全程保持高分辨率分支，多分辨率并行并反复融合，对关键点和分割都很强。

**6. Mask R-CNN（2017）**：实例分割的标杆。在 Faster R-CNN 基础上加一个 mask 分支，核心改进是 **RoIAlign**（用双线性插值取代 RoIPool 的两次取整量化，解决像素错位）。思路是"先检测再分割"，属于两阶段方法。

> 补充：FPN（特征金字塔）几乎是所有检测/分割框架的标配；YOLACT、SOLO 是单阶段实例分割。

## 三、Transformer 时代：核心算法

**1. ViT / SETR（2020-2021）**：ViT 把图像切成 patch 当 token 做全局自注意力。SETR 直接用 ViT 做编码器 + 简单上采样解码器做分割，证明纯 Transformer 可行。
- 缺点：单尺度特征、全局注意力计算量随图像大小平方增长。

**2. Swin Transformer（2021）**：**层级结构**（像 CNN 一样逐级下采样得到多尺度特征）+ **窗口注意力**（在局部窗口内计算，复杂度线性）+ **移位窗口**（让相邻窗口之间交互）。因此能直接替换 CNN backbone，接 UperNet、Mask R-CNN 等。

**3. SegFormer（2021）**：层级 Transformer 编码器（Mix-FFN 用卷积隐式提供位置信息，免去位置编码插值问题）+ 极简的**全 MLP 解码器**。高效、鲁棒，工程上很常用。

**4. DETR（2020）→ 范式转变**：检测任务用 **object queries + 匈牙利匹配**做集合预测，去掉了 anchor 和 NMS。它给分割带来了新思路。

**5. MaskFormer（2021）/ Mask2Former（2022）**：把分割统一成 **mask 分类**问题：用 N 个 query，每个 query 预测"一个 mask + 一个类别"。
- Mask2Former 的关键是 **Masked Attention**：query 的交叉注意力只关注上一层预测的 mask 前景区域，收敛更快、效果更好。
- 一个架构同时搞定语义、实例、全景分割，是该阶段的代表。

**6. SAM（2023）/ SAM 2（2024）→ 基础模型**：
- 任务：**可提示分割**（点、框、文本、mask 作为 prompt）。
- 结构：重型 ViT 图像编码器（MAE 预训练，只算一次）+ 轻量 prompt 编码器 + 轻量 mask 解码器（可实时交互）。
- 数据：自建数据引擎，SA-1B 约 1100 万图、10 亿+ mask。
- 特点：零样本泛化强；输出多个候选 mask 以解决歧义。
- SAM 2 加入记忆机制，扩展到视频分割。
- 常见组合：Grounding DINO + SAM（文本指定目标并分割）。

## 四、演进主线（面试可以这样总结）

| 阶段 | 关键思想 | 代表 |
|---|---|---|
| 1 | 全卷积、密集预测 | FCN |
| 2 | 融合多层特征，恢复细节 | U-Net、FPN |
| 3 | 多尺度上下文、扩大感受野 | DeepLab、PSPNet |
| 4 | 检测+分割，实例级 | Mask R-CNN |
| 5 | 全局建模：注意力 | SETR、Swin、SegFormer |
| 6 | 统一范式：query 做 mask 分类 | DETR、MaskFormer、Mask2Former |
| 7 | 大规模预训练 + 提示 | SAM、SAM 2 |

一句话总结：**从"局部感受野 + 手工设计的多尺度模块"，到"全局注意力 + 统一的 query 范式"，再到"大模型 + 提示的通用分割"。**

## 五、高频面试问题

1. **空洞卷积的作用与缺点？** 扩大感受野且不降分辨率；缺点是膨胀率不当会产生"网格效应"（gridding），丢失局部连续信息。
2. **U-Net 的 skip connection 为什么有效？** 补回下采样丢失的空间细节，并改善梯度传播。
3. **RoIAlign 和 RoIPool 的区别？** RoIPool 对坐标取整量化，造成错位；RoIAlign 用双线性插值保留浮点坐标，对 mask 精度很关键。
4. **常用损失函数？** 交叉熵、Dice Loss（缓解前景/背景不平衡）、Focal Loss（难样本）；通常组合使用（CE + Dice）。
5. **Swin 相比 ViT 的改进？** 层级特征、窗口注意力降复杂度、移位窗口实现跨窗口交互。
6. **Mask2Former 为什么能统一三种分割？** 因为都被建模为"一组 (mask, class) 对"，只是训练和推理时的后处理不同。
7. **Transformer 相比 CNN 做分割的优劣？** 优：全局上下文、扩展性强；劣：数据需求大、计算量大、局部细节和小目标处理需要额外设计。
8. **SAM 的局限？** 不输出语义类别；在医学影像、遥感、细长结构等领域零样本效果不稳定，常需微调；编码器较重。
9. **mIoU 怎么算？** 每个类别 IoU = 交集/并集，再对类别取平均。
