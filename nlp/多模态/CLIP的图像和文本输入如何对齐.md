CLIP 最核心的设计是：图像和文本的输入尺寸可以完全不同，但最终被映射成相同维度的向量，通过对比学习（Contrastive Learning）实现语义对齐。

你做过图像检索，可以直接把 CLIP 理解成：两个不同的特征提取网络，分别提取图像和文本特征，最后映射到同一个向量空间进行相似度计算。

## 1. 图像和文本分别编码成多少维？

以经典的 OpenAI CLIP ViT-B/32 为例：

| 项目     | 图像编码器      | 文本编码器        |
| ------ | ---------- | ------------ |
| 输入     | 224×224×3  | 最多 77 tokens |
| 主干网络   | ViT-B/32   | Transformer  |
| 主干隐藏维度 | 768        | 512          |
| 输出投影维度 | 512        | 512          |
| 最终特征   | `[B, 512]` | `[B, 512]`   |

其中 B 是 batch size。

注意：512 不是所有 CLIP 的固定维度。 不同型号可能是 512、768 或 1024 等，具体取决于架构配置。

## 2. 怎么对齐的？

假设一个 batch 有 3 对图文数据：

| 图片   | 配对文本               |
| ---- | ------------------ |
| 狗的图片 | "a photo of a dog" |
| 汽车图片 | "a photo of a car" |
| 猫的图片 | "a photo of a cat" |

图像编码器输出：

\\[ I \in \mathbb{R}^{3\times512} \\]

文本编码器输出：

\\[ T \in \mathbb{R}^{3\times512} \\]

首先对每一个向量做 L2 归一化，然后计算：

\\[ S = I T^{\mathsf T} \\]

得到一个 3×3 相似度矩阵。举个训练后的示意数值：

对角线是正确的图文配对；训练希望对角线的相似度高，其他位置低。

训练时使用对称的对比损失：

- Image → Text：给定一张图片，在 batch 的所有文本中找到正确描述。
- Text → Image：给定一段文本，在 batch 的所有图片中找到对应图片。

两种交叉熵损失取平均，并使用可学习的 temperature/logit scale 调整相似度分布。

这就叫 Contrastive Learning。

关键在于：对齐不是把图像的每一个 patch 和文本的每一个 token 一一对应，而是让整张图片的语义向量与整段文本的语义向量靠近。

## 3. 这里有一个容易误解的关键点

相同维度不代表已经语义对齐。

假设两个网络都输出 512 维，但它们未经联合训练，一个网络的第 1 维可能主要表示汽车相关特征，另一个网络的第 1 维却与完全不同的语义有关。

CLIP 真正的关键是：

1. 图像、文本编码器同时参与训练。
2. 正样本图文配对的相似度被提高。
3. 错误配对的相似度被压低。
4. 梯度反向传播，同时调整两个 Encoder 的参数和投影层。

所以不是先训练好两个互不相关的模型，再简单接上一个 512 维全连接层，就能自然对齐。

## 4. 图像内部是怎么从 Patch 变成 512 维的？

还是以 ViT-B/32 为例：

```
224 × 224 × 3
       ↓
32 × 32 Patch
       ↓
7 × 7 = 49 patches
       ↓
49 × 768
       ↓
增加 CLS Token + 位置编码
       ↓
50 × 768
       ↓
12层 Transformer
       ↓
取 CLS Token
       ↓
768维
       ↓
Linear Projection
       ↓
512维
```

文本则是经过 Token Embedding、Text Transformer，取结束标记 EOT 对应的表示，再投影到 512 维。以上尺寸与经典 CLIP 架构一致。

## 5. 这和你过去的图像检索有什么联系？

过去你的图像检索是：

\\[ Image \xrightarrow{CNN} \mathbb{R}^{512} \\]

再利用 FAISS 做最近邻搜索。

CLIP 则是：

\\[ Image \xrightarrow{ViT} \mathbb{R}^{512} \\]

\\[ Text \xrightarrow{Transformer} \mathbb{R}^{512} \\]

然后两种模态都可以拿来检索。

CLIP 的重大创新不在于把向量变成 512 维，而在于通过图文对比学习，让两种模态的向量具有可比较的语义。

还有一个重要边界：CLIP 能对齐整张图和文本的全局语义，但这不等于它天然具备精确的目标定位、OCR 字符识别或复杂空间关系推理能力。
